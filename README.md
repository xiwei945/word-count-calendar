# 字数统计日历 - Obsidian Plugin

一个 Obsidian 插件，以美观的日历视图展示每日写作字数统计。

## 功能特性

✨ **日历视图**：直观展示每月写作数据
📊 **智能统计**：支持中英文混合词数统计
🎨 **渐变色显示**：根据目标完成度显示不同颜色
📁 **文件夹过滤**：可配置包含/排除文件夹
💾 **自动保存**：字数自动保存到笔记属性"码字数"

## 安装方法

### 开发模式

1. 将此文件夹复制到你的 Obsidian vault 的 `.obsidian/plugins/` 目录下
2. 在此目录运行：
   ```bash
   npm install
   npm run dev
   ```
3. 在 Obsidian 设置中启用"字数统计日历"插件
4. 点击左侧 ribbon 的日历图标打开视图

### 生产构建

```bash
npm run build
```

## 使用说明

### 打开日历视图

- 点击左侧 ribbon 的日历图标
- 或使用命令面板：`打开字数统计日历`

### 设置

在插件设置页面可以配置：

- **每日目标字数**：设置你的写作目标（默认 1000 字）
- **包含文件夹**：只统计指定文件夹（留空表示全部）
- **排除文件夹**：不统计指定文件夹

### 颜色说明

- 🔴 **深红 → 浅红**：未达目标，字数越多颜色越浅
- 🟢 **浅绿 → 深绿**：达到目标，字数越多颜色越深
- ⚪ **白色**：当天无写作数据

### 字数统计规则

- 中文按字数统计（每个汉字算一个词）
- 英文按单词统计（空格分隔）
- 不统计标点符号
- 只统计正文内容（排除 frontmatter、代码块等）

## 命令

- `打开字数统计日历`：打开日历视图
- `更新当前文件字数`：手动更新当前文件的字数
- `更新所有文件字数`：扫描并更新所有文件的字数
